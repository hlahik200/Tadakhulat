منصة أثر — نسخة الاستضافة
==========================

محتويات المجلد:
- index.html       المنصة كاملة (لا تعدّل فيه شيئاً)
- config.js        مفاتيح الربط بقاعدة البيانات — هذا الملف الوحيد الذي تعدّله
- firestore.rules  قواعد الحماية التي تُلصق في Firebase
- vercel.json      إعداد اختياري عند الرفع على Vercel

الخطوة 1: قاعدة البيانات (Firebase — مجانية)
1) ادخل https://console.firebase.google.com بحساب Google ← «إضافة مشروع» ← اسم: athar ← أكمل (يمكن إيقاف Analytics).
2) من القائمة: Build ← Firestore Database ← Create database ← اختر الموقع me-central2 (الدمام) ← Production mode.
3) تبويب Rules ← احذف الموجود والصق محتوى firestore.rules ← Publish.
4) إعدادات المشروع (رمز الترس) ← Your apps ← رمز الويب </> ← سجّل التطبيق ← انسخ قيم firebaseConfig.
5) افتح config.js بأي محرر نصوص والصق القيم بين علامات التنصيص، ثم احفظ.

الخطوة 2: الاستضافة (اختر طريقة)
أ) الأسهل — Netlify Drop:
   ادخل https://app.netlify.com/drop واسحب المجلد كاملاً وأفلته. يظهر لك رابط المنصة فوراً.
   سجّل الدخول بعدها ليبقى الموقع دائماً، ويمكنك تغيير اسم الرابط من Site settings.
ب) Vercel:
   ارفع محتويات المجلد إلى مستودع GitHub جديد، ثم في https://vercel.com: Add New ← Project ← اختر المستودع ← Deploy.
ج) GitHub Pages:
   ارفع المحتويات إلى مستودع ← Settings ← Pages ← Branch: main ← Save.

الخطوة 3: أول تشغيل
- افتح رابط المنصة ← «المشرفون» ← أنشئ حساب المسؤول الأول (الاسم والرقم السري).
- من «الإدارة» أضف بقية المشرفين والمدارس، أو جرّب بـ«إضافة بيانات تجريبية» ثم احذفها.
- تأكد أن الشريط أعلى الصفحة يقول «متصل — البيانات محفوظة ومشتركة». إن قال «وضع محلي» فمفاتيح config.js غير صحيحة.

ملاحظات
- القواعد المرفقة تسمح بالقراءة والكتابة لمن يملك الرابط حتى 30 يونيو 2027 (فترة التجربة)، ثم تتوقف الكتابة حتى تُمدَّد.
- الرقم السري للمشرفين يحجب لوحتهم عن الزوار ولا يشفّر البيانات؛ لا تُدخل بيانات شخصية للطلاب.
- الخطة المجانية في Firebase (50 ألف قراءة يومياً) تكفي فترة التجربة؛ كل فتح للمنصة يقرأ كل الاستمارات، فإذا كثرت المدارس والأسابيع راقب الاستهلاك من لوحة Firebase.
